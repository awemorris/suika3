Suika Beat
==========

3レーンのリズムゲームです。
720×1280のスマホ向き縦型画面、34秒の曲と61ノーツの譜面を収録しています。

## 起動

このディレクトリを作業ディレクトリにして、Suika3 を起動してください。

## 遊び方

- PLAY! → 練習 → LET'S PLAY → カウントダウン → 演奏 → 結果。
- ノーツが白い判定線に来たら、下の3ボタンをクリック／タップ、または D / F / J。
- PERFECT は1,000点、GOOD は500点。最大61,000点です。
- PLAY AGAIN で再挑戦、TITLE または Escape でタイトルへ戻ります。
- タイトルで音量とタイミング補正（±200 ms）を調整できます。
- ベストスコアと設定は起動中のみ保持します。同時押し・一時停止はありません。
